🚀 Power BI HTML & SVG KPI Library
Uma coleção de componentes visuais avançados para Power BI, utilizando DAX + HTML/SVG. Esta biblioteca foi criada para superar as limitações de design dos visuais nativos, permitindo criar dashboards altamente customizáveis e modernos.

📋 Componentes Disponíveis
1. Ranking HTML KPI com Título
Um componente de lista dinâmica que exibe um ranking com ícones de medalhas (Top 3) e suporte a scroll.

Tecnologia: DAX + HTML/CSS.

Visual Recomendado: HTML Content.

🛠️ Como Usar
Abra a pasta do componente desejado (ou o arquivo .txt).

Copie o código DAX.

No Power BI, crie uma Nova Medida.

Cole o código e ajuste as variáveis na seção CONFIGURAÇÕES DO USUÁRIO.

Certifique-se de que a categoria de dados da medida esteja definida como Web URL (se necessário pelo visual escolhido).
